How to use

                                
    
                                    
  1. Open Burp Suite. Go to Proxy > Options and confirm a listener is running on port 8080.
    2. 
                                    
  2. In the Scripts section, add hooks\safiye_redirect.js as an extra script. For HTTPS targets also add hooks\safiye_ssl_unpin.js.
    3. 
                                    
  3. Set the ports in the toolbar to match your environment, then click Start Bridge.
    4. 
                                    
  4. Spawn or attach the target process. Traffic will flow: App → Bridge → Burp → Server.
    5. 
                                    
  5. Inspect and modify requests in Burp Proxy > Intercept. Requests also appear in Safiye History tagged with the destination host.
    6. 
                                

                            

                            
The redirect script patches WinHTTP, WinInet, Python HTTP libraries (requests, httpx, aiohttp, urllib3), and libcurl. Apps that bypass the system proxy or use a custom networking stack may need additional hooks.

4. Findings will stream automatically into the Vulnerabilities tab
